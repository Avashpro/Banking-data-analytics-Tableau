# 🏦 Banking Data Analytics — Tableau

This project focuses on analyzing banking data using **Tableau** to uncover insights, trends, and visual patterns. It was developed to strengthen skills in data visualization, dashboard development, and business analytics.

## 📌 Project Overview

The goal of this project is to:
- Explore real banking data
- Clean and prepare data for analysis
- Create interactive dashboards in Tableau
- Derive actionable insights from transaction and customer behavior

The project highlights how visual analytics can support data-driven decision making in the banking domain.

---

## 📁 Dataset

The dataset used in this project is included in the repository.  
It contains customer information, transaction history, account balances, and other banking-related attributes that help analyze trends and patterns.
